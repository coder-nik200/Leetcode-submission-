💻 Example

One of the problems in this repository is Sort Colors, where the goal is to sort an array containing only 0, 1, and 2 without using the built-in sorting function.

The optimized approach uses the Dutch National Flag algorithm with three pointers and runs in:

Time Complexity:  O(n)
Space Complexity: O(1)
