🔥 Featured Solution

Sort Colors

Problem: Sort an array containing only 0, 1, and 2 without using the built-in sorting function.

Algorithm: Dutch National Flag

Time Complexity  → O(n)
Space Complexity → O(1)

The solution uses three pointers:

low  → 0s
mid  → current element
high → 2s

This sorts the array in a single pass without using an additional array.
